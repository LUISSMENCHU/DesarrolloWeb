Detalle: 
Se realizó la migración del sitio web de la excursión a Semuc Champey hacia una aplicación modular utilizando React. Se organizaron las diferentes funcionalidades en componentes reutilizables, incluyendo la galería interactiva de imágenes, la calculadora de cotización con actualización automática, el filtro de actividades, el formulario de reservación con validación y la sección de testimonios con cambio de opiniones. También se mantuvo un diseño adaptable utilizando Bootstrap y se organizaron las imágenes y componentes dentro de la estructura del proyecto React. Finalmente, el proyecto fue publicado en Netlify y se verificó el funcionamiento de sus principales funcionalidades.
